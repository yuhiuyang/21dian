# 21点游戏（Blackjack21）

一款纯原生开发的安卓 21 点（Blackjack）纸牌游戏。

**这是一个 Vibe Coding 作品**：人类只负责提需求、给参考图和验收，从总体方案、规则引擎、UI 美术、动画音效，到性能优化、签名发布，全部由 AI 编程助手（ZCode / GLM）在多轮会话中完成，人类没有手写一行代码。

## 功能特性

- **完整 21 点规则**：Blackjack、要牌/停牌、爆牌、加倍（Double）、庄家规则、筹码结算、多局连打、破产出局
- **1~4 人本地对战**：真人、CPU 同桌混玩，单机即可开一桌
- **3 种 AI 对手**：保守 / 均衡 / 激进三种策略，参数经过大规模模拟对局校准
- **全程序化绘制**：牌桌、卡牌、筹码、按钮、头像全部用 Canvas 代码画出，无第三方图片素材
- **程序合成音效 + 震动反馈**：音效由代码实时合成，APK 里没有任何音频文件
- **全中文界面**，适配多种分辨率与密度（手机 / 平板 / 模拟器）
- **性能讲究**：空闲时零重绘（0 帧/秒）、动画稳定 60fps、后台自动暂停

## 下载安装

直接下载本仓库 [`apk/Blackjack21-v1.0.0-release.apk`](apk/Blackjack21-v1.0.0-release.apk)（约 0.9 MB），传到安卓手机安装即可，支持 Android 7.0+。

也可以到 [Releases](../../releases) 页面获取各版本安装包。

## 技术栈

- **Kotlin + Android 原生 View + Canvas**：刻意不使用 Compose / Unity / Flutter / 游戏引擎 / WebView
- **零第三方依赖**：游戏逻辑与 UI 全部基于标准库，仅单元测试使用 JUnit4
- minSdk 24 / targetSdk 35，release APK 经 R8 压缩后约 0.9 MB

## 构建与测试

```bash
# 需要 JDK 17 与 Android SDK
./gradlew assembleDebug            # 构建调试包
./gradlew assembleRelease          # 构建发布包（签名密钥未入库，克隆后得到未签名包）
./gradlew :app:testReleaseUnitTest # 运行单元测试
```

游戏规则与结算是**测试驱动**的：93 个单元测试覆盖洗牌、点数、Blackjack 判定、爆牌、结算、多局流程、CPU 策略与多人对战，全部通过（0 失败）。

## 工程结构

```
app/src/main/java/com/blackjack21/
├── game/        # 规则引擎：牌、手牌、牌堆、庄家、玩家、结算（纯 Kotlin，可独立测试）
├── ai/          # CPU 对手策略
├── ui/          # 渲染层：牌桌/卡牌/筹码/按钮/头像 Canvas 绘制、动画、音效
└── MainActivity # 生命周期与前后台暂停恢复
app/src/test/     # 93 个单元测试
art/              # 应用图标生成源码与源图
```

## 关于 Vibe Coding

这个项目的开发流程：

1. 人类写下一份《安卓 21 点小游戏开发总体方案》（约 27 节），作为 AI 唯一需求依据；
2. AI 按方案分 12 个阶段推进：**先规则 → 再游戏 → 再美术 → 再动画 → 最后优化**，每轮会话结束更新进度文档；
3. 规则与结算不许"手点验证"，必须配自动测试；
4. 中间踩过的坑（中文路径构建、模拟器截图撕裂、后台动画生命周期等）都记录在案，逐轮解决。

整个过程没有人工编写或修改过任何一行代码。
